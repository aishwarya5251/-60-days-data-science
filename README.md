# Day 1: Python Basics | 60 Days of Data Science

## Objective

Strong Data Scientists are strong Python programmers. Today I learned the fundamentals of Python by working with variables, data types, user input, operators, and dictionaries.

## Topics Covered

* Variables
* Data types (`int`, `float`, `str`, `dict`)
* User input & output
* Arithmetic operators
* Dictionary creation and access

## Project

Built a Python script (`day1.py`) that:

* Takes **name**, **age**, and **monthly salary** as input
* Calculates the **yearly salary**
* Stores all information in a dictionary
* Displays the results in a clean format

## Example Output

Name: Aishwarya
Age: 19
Monthly Salary: ₹30,000
Yearly Salary: ₹3,60,000

## Learning Outcome

This exercise strengthened my understanding of Python basics, which form the foundation for data analysis, automation, and machine learning.
